# Canan (Wipavee Pinyamuksapong) — Portfolio 2026

Responsive UX/UI, Product Design & WordPress Portfolio website featuring interactive folder navigation, smooth CSS/JS animations, and lightbox image previews.

## Folder Structure
- `index.html` — Main responsive website (Tailwind CSS 3.4.17 + custom animations)
- `assets/` — All portfolio images, cutouts, sitemaps, moodboards, and product photos

## Deploy to GitHub Pages
1. Create a new repository on GitHub (or use `wipaveenan.github.io` for your main site).
2. Upload `index.html` and the entire `assets/` folder to the root of the repository.
3. Go to **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
4. Your live site will be available at `https://wipaveenan.github.io/`.
